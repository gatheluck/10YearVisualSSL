# Website development

This branch owns the static research website. Keep the displayed figure data,
scientific interpretation, provenance and browser checks together. The research
implementation is maintained on main. See README.md for preview and release.

Write a failing browser or content test first. Run npm test and keep the site
branch hooks enabled. Use feature branches and PRs into codex/paper-website.
Publish via a reviewed PR to gh-pages with explicit release authorization.
