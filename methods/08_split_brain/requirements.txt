# What the 08_split_brain port's own files import, and nothing else. Checked in
# both directions by tests/test_method_requirements.py. Floors only; the exact
# hashed closure is in requirements.lock.txt (CPU) and requirements.lock.cu130.txt.
#
# A self-contained re-implementation (the lab's own Split-Brain code, no
# submodule): the two cross-channel AlexNets, the numpy RGB->Lab conversion, the
# numpy L/ab quantisation, the dataset, the trainer and the probe are all here.
# The capture's dataset used scipy.spatial.cKDTree and skimage.color, but its own
# comment states the released ab target IS NumPy argmin, so the port uses numpy
# and depends on neither. torch is imported directly; numpy runs the
# Lab/quantisation and seeds the run; torchvision provides the ImageFolder and
# transforms; PyYAML loads a YAML config. timm supplies the two half-width
# ViT-B/16 branches for the unified Step-2 path (arch: vit), imported lazily so
# the native AlexNet path does not need it.
