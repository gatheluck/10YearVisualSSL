# The full environment for 21_barlow_twins, pinned and hashed.
#
# A closure, not a wish list: every package that gets installed is named here.
# Install with hash checking:
#
#   pip install --require-hashes \
#       --index-url https://download.pytorch.org/whl/cpu \
#       --extra-index-url https://pypi.org/simple \
#       -r methods/21_barlow_twins/requirements.lock.txt -r requirements-tools.lock.txt
#
# Wheels are listed for CPython 3.12 on linux x86_64, linux aarch64 and macOS
# arm64. A platform whose wheel is not listed fails loudly rather than
# installing something unverified.
#
# **Measured, not copied.** The declared floors were installed into a fresh
# environment and the result compared with the previous method's lock: 22
# packages against 22, identical but for Markdown, which had released 3.10.3
# in between. Pillow is a declared requirement here rather than only a
# dependency -- this method's augmentation is built on PIL -- but it was
# already in the closure, so the set does not change.
#
# **Markdown is held at 3.10.2 deliberately.** The locks are installed
# together, so two of them naming different versions of one package is an
# environment that cannot exist, and verify-environment refuses to read them
# rather than letting one win in silence.
#
# These are the versions this port was verified against, not the versions the
# captured cluster runs used. Those are not recoverable; see README.md.
