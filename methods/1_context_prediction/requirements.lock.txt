# The full environment, pinned and hashed.
#
# **This is a closure, not a wish list.** Every package that gets installed is
# named here, including torch's own dependencies. The previous version of this
# file pinned 3 packages while 12 were installed, so nine floated -- and a
# floating dependency means the environment cannot be rebuilt.
#
# Install with hash checking, which pip enables for the whole file as soon as
# one hash is present:
#
#   python3 -m venv .venv && . .venv/bin/activate
#   pip install --require-hashes \
#       --index-url https://download.pytorch.org/whl/cpu \
#       --extra-index-url https://pypi.org/simple \
#       -r methods/1_context_prediction/requirements.lock.txt
#
# Two wheels are listed per package where they differ by platform: CPython
# 3.12 on linux x86_64 (manylinux_2_28) and on macOS arm64. pip accepts an
# artifact matching any listed hash. **A platform whose wheel is not listed
# fails loudly** rather than installing something unverified -- add its hash
# deliberately.
#
# Interpreter: see .python-version at the repository root. These are cp312
# wheels and will not install on another minor version.
#
# **These are the versions this port was verified against**, not the versions
# the captured cluster runs used. Those are not recoverable: the environment
# directories were classified as artifacts and never captured, and
# setup_conda_env.sh pins nothing. The record fixes Python 3.10 and CUDA 12.1
# and no more. See README.md.
#
# For a GPU build, use the matching CUDA index (for example
# .../whl/cu121). Its wheels have different hashes, which are not listed here
# because none was installed or run on this machine.
#
# Regenerated by resolving the direct requirements and hashing the wheels for
# both platforms; the exact procedure is in README.md.
