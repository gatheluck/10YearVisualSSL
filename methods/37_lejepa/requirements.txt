# no pretrained download, so the run stays hermetic); torchvision provides the
# ImageFolder and transforms; numpy backs the seeding; PyYAML is read to load a
# YAML config on the stand-alone path. No transformers/xformers/faiss; the
# upstream SIGReg package is NOT imported (reimplemented locally); TensorBoard and
# tqdm are dropped, and the captured DDP/AMP paths are not ported.
